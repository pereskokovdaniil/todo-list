# ToDo List

Трехколончатый менеджер задач с сохранением в localStorage

## Возможности
- Добавление, удаление, перемещение задач
- Дата создания каждой задачи
- Сохранение данных в браузере

## Технологии
- HTML
- CSS
- Vanilla JS
- localStorage

## Адаптивность
Поддерживаются все устройства с шириной экрана от 375px.
